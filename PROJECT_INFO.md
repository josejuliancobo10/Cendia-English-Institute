## 📁 Estructura y Archivos del Proyecto

Ruta local permanente:  
`C:\Users\Usuario\.gemini\antigravity\scratch\cendia-website\`

- **`index.html`**: Página web completa con diseño responsive, Hero, Cursos, Testimonios, Precios, FAQ, Formulario con WhatsApp, Chatbot y Footer.
- **`styles.css`**: Efectos de pulso WhatsApp, animaciones flotantes y estilos personalizados.
- **`app.js`**: Asistente virtual (Chatbot con respuestas inteligentes), validación de formulario y modal de confirmación.
- **`vercel.json`**: Configuración de enrutamiento estático en Vercel.
- **`deploy_vercel.bat`**: Script de 1 solo clic para publicar futuras actualizaciones a Vercel.
- **`push_to_github.ps1`**: Script para sincronizar cambios locales con el repositorio de GitHub.
- **`server.ps1`**: Servidor web local para probar en `http://localhost:8080`.
